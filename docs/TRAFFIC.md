# Πραγματική κίνηση — first-party visitor counter & console

**Πρόβλημα:** το GA4 είναι consent-gated *και* το κόβουν τα ad-blockers, οπότε
υποεκτιμά τους πραγματικούς επισκέπτες κατά ~50%. Αλλαγή vendor (Cloudflare/Plausible
cloud) δεν βοηθά — τα beacons τους είναι στις ίδιες filter-lists.

**Λύση:** μετράμε στο **δικό μας** origin. Ο client πινγκάρει `/api/hit` (καθαρό
same-origin path, σε καμία adblock λίστα) και μια Netlify function μετράει. Νικάει και
τα δύο εμπόδια:

- **Ad-block** — first-party request στο δικό μας domain, δεν μπλοκάρεται.
- **Consent** — 0 cookies, 0 προσωπικά δεδομένα αποθηκευμένα → νόμιμο χωρίς banner.

## Πώς μένει ανώνυμο (γιατί δεν χρειάζεται consent)

Ο επισκέπτης ταυτοποιείται μόνο με μη-αναστρέψιμο **ημερήσιο** hash:

```
visitor   = sha256( dailySalt + "|" + ip + "|" + userAgent )
dailySalt = sha256( TRAFFIC_HASH_SECRET + "|" + utcDay )   # αλλάζει κάθε μέρα
```

Το salt δεν αποθηκεύεται ποτέ. Άρα το hash δεν αντιστρέφεται σε IP, και ο ίδιος
επισκέπτης παίρνει **διαφορετικό** hash αύριο → κανένα cross-day tracking, μηδέν
προσωπικά δεδομένα σε ηρεμία. (Το μοντέλο του Plausible.)

Η μοναδικότητα μετριέται **race-free**: κάθε μοναδικός επισκέπτης γράφει ένα blob
`d/<μέρα>/<hash>`· επανάληψη επίσκεψης απλώς ξαναγράφει το ίδιο key. Ο αριθμός των
keys μιας μέρας = ακριβής αριθμός μοναδικών.

## Τα τρία είδη ping

| Ping | Πότε | Τι κάνει |
|------|------|----------|
| *(κανένα flag)* | κάθε pageview / SPA navigation | μετράει προβολή, μοναδικό, breakdowns |
| `hb=1` | κάθε 60″ **όσο η καρτέλα είναι ορατή** (max 1 ώρα) | «είναι ακόμη μέσα» + πραγματικός χρόνος παραμονής |
| `a=<action>` | nav / share / fav / out / search / filter | οι ενέργειες που μοιάζουν με conversion |

Ο heartbeat είναι αυτός που κάνει τον «μέσο χρόνο» **μετρημένο** αντί για μαντεψιά,
και δίνει το «ποιοι είναι μέσα τώρα». Σταματά όταν η καρτέλα φύγει στο background,
ώστε μια ξεχασμένη καρτέλα να μη φουσκώνει τους μέσους όρους.

Οι ενέργειες μπαίνουν από το `trackEvent` (`services/analyticsService.ts`) **πριν**
το consent gate — δεν αποθηκεύουν τίποτα προσωπικό, και είναι ο μόνος τρόπος να
δούμε conversions από το μισό κοινό που το GA4 δεν βλέπει ποτέ.

## Τι κρατάμε στο Netlify Blobs

| Key | Τι είναι |
|-----|----------|
| `d/<μέρα>/<hash>` | ένα blob ανά μοναδικό επισκέπτη → **ακριβείς** μοναδικοί· μέσα κρατά ρολόι session + ποια βήματα έκανε |
| `geo/<μέρα>/<hash>~cc~lat~lon~city~device~kind~a` | τα δεδομένα του χάρτη **μέσα στο ίδιο το key** — μια `list()` και μηδέν reads |
| `live/<λεπτό>/<hash>~cc~lat~lon~city~section~a` | παρουσία· «ποιος είναι online τώρα» = τα keys των τελευταίων 5 λεπτών |
| `totals/<μέρα>` | best-effort rollup: προβολές, χώρες, πόλεις, γλώσσες, ώρες, δραστηριότητα, διαδρομή, χρόνος |

Τα `live/` σκουπίζονται μόνα τους: κάθε φόρτωμα του console σβήνει keys > 90 λεπτών.

## Setup (2 env vars στο Netlify → Site settings → Environment variables)

| Var | Τι | Αν λείπει |
|-----|-----|-----------|
| `TRAFFIC_HASH_SECRET` | Τυχαία μυστική συμβολοσειρά (π.χ. `openssl rand -hex 32`). Κάνει το hash πραγματικά μη-σπάσιμο. | Δουλεύει, αλλά με public fallback salt (λιγότερη ανωνυμία). **Βάλε το.** |
| `TRAFFIC_STATS_KEY` | Μυστικό για να δεις το console. | Το `/api/traffic` επιστρέφει 403 (ποτέ δημόσιο). |

Χωρίς redeploy δεν ισχύουν — άλλαξε τα env vars και κάνε redeploy.

## Πού βλέπω τους αριθμούς

```
https://calmbeach.gr/api/traffic?key=ΤΟ_TRAFFIC_STATS_KEY
        &days=7|30|90       παράθυρο (default: ό,τι έχει μετρηθεί, max 90)
        &format=json        raw δεδομένα
        &format=live        μόνο το live layer (αυτό που κάνει auto-refresh)
        &reset=2026-07-30   σβήνει ΟΛΗ τη μέρα (μολυσμένη μέρα δοκιμών)
```

Το console δείχνει: ποιοι είναι online **τώρα** πάνω σε παγκόσμιο χάρτη, από πού
μπήκαν, τι κάνουν (παραλία / οδηγός / περιοχή / πλοήγηση), παλμό τελευταίας ώρας,
ημερήσια πορεία, ώρες αιχμής, χώρες, πόλεις, κανάλια, συσκευές, γλώσσες,
δημοφιλέστερες σελίδες. Ανανεώνεται μόνο του κάθε 20″.

**Το παράθυρο ξεκινά από τη μέρα που άρχισε η μέτρηση.** Οι μέρες προκύπτουν από το
ίδιο το blob store, οπότε μέρες πριν υπάρξει ο μετρητής δεν εμφανίζονται ποτέ σαν
«0 επισκέπτες» — ένα μηδενικό που δεν μετρήθηκε είναι ψέμα και ισοπέδωνε τα γραφήματα.

## Πόσο ακριβές είναι το κάθε νούμερο

| | Τι |
|---|---|
| **ακριβές** | μοναδικοί ανά μέρα· «είδαν ≥2 σελίδες» (το μετράει ο ίδιος ο client, όχι εικασία) |
| **κατά προσέγγιση** | προβολές, χώρες, συσκευές, χρόνος, διαδρομή — read-modify-write rollup, σε ταυτόχρονες επισκέψεις χάνεται καμιά· **υποεκτιμούν, ποτέ δεν φουσκώνουν** |
| **εκτίμηση** | «≈ Άτομα»: κάτω άκρο = όσοι πιάστηκαν με ετικέτα νέος/επιστρέφων, πάνω άκρο = μοναδικές συσκευές/συνδέσεις (κινητό με αλλαγμένη IP μετριέται 2 φορές). Φαίνονται **και τα δύο άκρα**. |

Ο χάρτης δείχνει την πόλη που δίνει το δίκτυο· όπου δεν υπάρχει πόλη μπαίνει το κέντρο
της χώρας και ο κύκλος σχεδιάζεται **κούφιος**, ώστε να μη διαβαστεί σαν μετρημένη θέση.

## Αρχεία

- `netlify/functions/pageview.mjs` — δέκτης beacon + hashing + Netlify Blobs.
- `netlify/functions/traffic-stats.mjs` — το προστατευμένο console (server-rendered).
- `netlify/functions/lib/geoLookup.mjs` — geo από τα edge headers + centroids χωρών.
- `netlify/functions/lib/worldPath.mjs` — το περίγραμμα του κόσμου ως ένα SVG path.
- `scripts/buildWorldPath.mjs` — one-off γεννήτρια του παραπάνω (Natural Earth 110m).
- `services/pageviewBeacon.ts` — ο client: pageview, heartbeat, actions.
- `netlify.toml` — τα `/api/hit` και `/api/traffic` redirects.

## Σημειώσεις

- Μετράει μόνο σε production build (`VITE_APP_ENV=production`). Preview/branch/local: off.
- Bots/crawlers κόβονται server-side (UA screen) ώστε «πραγματικοί» = πραγματικοί.
- Κουμπί «Μην μετράς αυτή τη συσκευή» στο console — κρατά τις δικές σου επισκέψεις έξω.
- Ο χάρτης δεν έχει preset «Ελλάδα»: τα δεδομένα ακτογραμμής είναι 110m και **δεν
  περιέχουν ελληνικά νησιά**. Το «πού στην Ελλάδα» το απαντά η λίστα πόλεων.
- Τα per-visitor blobs μένουν επ' αόριστον· σε πολύ μεγάλο όγκο, πρόσθεσε scheduled
  cleanup που σβήνει partitions `d/<μέρα>/…` και `geo/<μέρα>/…` παλιότερες από ~90 μέρες.
