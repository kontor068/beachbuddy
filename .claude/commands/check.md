Τρέξε τους ελέγχους ποιότητας του project και ανάφερε **μόνο τα προβλήματα**.

1. `npm run lint`
2. `npm run contract:check`
3. `npm run quality:critical`

Αν σου δόθηκε όρισμα (`$ARGUMENTS`), τρέξε επιπλέον και `npm run quality:$ARGUMENTS`.

**Κανόνες αναφοράς:**
- Μην κάνεις paste το output. Ποτέ.
- Για κάθε αποτυχία: μία γραμμή «τι θα έβλεπε ο επισκέπτης» + το αρχείο (`file.ts:42`).
- Αν πέρασαν όλα: γράψε **μία** γραμμή, «Όλα πράσινα» και σταμάτα.
- Μη διορθώσεις τίποτα χωρίς να σου ζητηθεί. Στο τέλος πρότεινε τι θα διόρθωνες πρώτο
  και γιατί, σε μία πρόταση.
